# Jazz Solo Generator

This project implements a hierarchical, phrasing-aware jazz solo generator trained on the Weimar Jazz Database. The model is conditioned on chord changes and artist style, with initial support for iconic improvisers Charlie Parker and Miles Davis. By capturing melodic phrasing at multiple levels of abstraction—from individual note choices to long-range phrase arcs—the system aims to produce solos that reflect authentic jazz language, idiomatic vocabulary, and stylistic nuance appropriate to the given harmonic context and target artist.
